# scripts/

Ready-to-use scripts are generated by `../configurator.html`. Open that file in a
browser, fill in your values, and download the filled scripts.

This folder contains **templates** for people who prefer to edit placeholders by hand.
Every `<PLACEHOLDER>` must be replaced before use.

| Template | Purpose | Placeholders |
|---|---|---|
| `backup-169429.bat.example` | Back up factory firmware (4.5 h) | `<PROJECT_DIR>`, `<PYTHON_EXE>` |
| `provision-wifi.bat.example` | Pair controller to WiFi via Bluetooth | `<PROJECT_DIR>`, `<WIFI_SSID>` |
| `start-flasher.bat.example` | Launch the local WebHID flasher | `<PROJECT_DIR>`, `<PYTHON_EXE>` |
| `dnsmasq-stadia.conf.example` | Router DNS rule for the controller only | `<CONTROLLER_MAC>`, `<PC_IP>`, `<CONTROLLER_IP>` |

The generated set additionally includes `start-receiver.vbs`, `restart-receiver.vbs`
and `autostart-receiver.vbs`, which contain the receiver command line with your IPs
and paths filled in.

All scripts are plain ASCII with CRLF line endings so Windows runs them cleanly.
